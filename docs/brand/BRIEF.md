# Stage Director logo brief (concepts only, nothing approved)

- **Name:** Stage Director. Self-hosted deploy dashboard: local → staging → live, plain-English buttons, only code owners put things live.
- **Audience:** small web team and site owners; mostly non-technical people pressing the buttons.
- **Adjectives:** friendly, calm, trustworthy, in charge, simple.
- **Owner's idea:** a star on the back of a director's chair (the director decides when the show goes live).
- **Category clichés to avoid:** rockets, arrows, pipelines, clapperboards (🎬 is what the README uses today).
- **Must work:** 16 px favicon, one colour, reversed; app palette teal #0f8f8a / blue #2563b8 (colour later).
- **Not this brand:** Aibacus brand files do not apply.
